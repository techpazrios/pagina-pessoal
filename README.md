# Página Pessoal Simples

Este projeto é uma atividade prática da disciplina de **Programação Web I** do Curso Técnico em Informática para Internet (IF Sudeste MG - Campus Barbacena).

## 🚀 Tecnologias Utilizadas
- HTML5 (Estruturação e HTML Semântico)

## 📁 Estrutura do Projeto
- `index.html`: Página principal de apresentação.
- `sobre.html`: Página com informações adicionais.
- `img/`: Pasta contendo os arquivos de imagem.
